# Sotto deterministic fixture corpus

All audio here is synthetic speech generated by the macOS `say` command and contains no
recording of a real person. The WAVs are 16 kHz, mono, 16-bit PCM and exactly 30 seconds
long. Mic tracks use the Samantha voice and system tracks use Daniel, so stream and
speaker separation are independently testable. Silence and music remain synthetic
negative cases.

`call-01-mic.wav` and `call-01-sys.wav` are the canonical paired call. Its timestamped
frames change from an overview slide to a pricing slide at 15 seconds. Expected labels
are recorded in `call-01-ground-truth.json`. The slides are rendered with AppKit system
fonts, and the macOS integration test asserts that Apple Vision reads “Enterprise
Pricing” from the pricing frame.

The remaining cases are: objection/competitor, heavy crosstalk, long silence,
silence-only, and music-only. Regenerate binary assets deliberately with:

```sh
cargo run -p cli --example generate_fixtures
```

Generation intentionally requires macOS because `say`, `afconvert`, AppKit font
rendering, and Vision verification are part of the fixture provenance.

The reference timeline is the stdout of an actual full CLI run through
`core::Pipeline`, using real Silero, prosody, Apple Vision, and whisper.cpp's
`tiny.en-q5_1` model—not a hand-authored approximation or a separate CLI pipeline. For stable replay, its generated
session id is normalized to `1` and temporary cached frame references are replaced by
their source fixture paths; event timestamps, VAD boundaries, OCR, ASR text, and prosody
are preserved from the run. It is stable JSONL intended for downstream replay tests. A
diff is a contract signal and should be reviewed.
