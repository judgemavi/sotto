    Storage & privacy

    What Sotto keeps, where it lives, and the one case where anything leaves this Mac.

    ⌂ Recordings stay on this Mac Audio, video, and transcripts are stored in ~/Library/Application Support/Sotto and are never uploaded. Each one is listed below with its size, and deleting it here deletes the files.
    → Summaries can use a cloud model When you summarize or ask, the transcript text for that request is sent to the provider you chose. The recording itself never is.

    Delete all recordings Removes every recording, transcript, and summary. There is no server copy to recover from.
