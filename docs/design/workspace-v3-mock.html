⇉ Notes are two-way Every entry is one .md file. Edit a block in Sotto or in the file — both land in the same edit overlay, and your wording is kept verbatim either way.
→ The record is one-way Transcripts are projected read-only. Editing transcript text in a file changes the file, never the record — the recording on this Mac stays the source of truth.
Mirror entries to a folder Written locally as entries change. Nothing is uploaded by Sotto; the folder is yours to sync or not.

One file per entry 2026-08-14 sprint-42-planning.md — frontmatter carries date, participants, and each recording's captured target as facts.
Blocks keep their identity Every block ends in a stable anchor — ^b7f2c1 — so other tools can reference it and a regeneration can merge around your edits.
Citations link back sotto://entry/9f31/r2/12:41 opens this Mac's Sotto at that transcript row. Series affiliation is a wiki-link: [[Weekly standup]].

Point Obsidian — or any Markdown app — at the folder for links, backlinks, graph, search, and mobile. Sotto builds none of that itself: the vault is the whole integration.
